# BattleStarSol

The standalone themed launch page for a clean browser tab.

This repository is one of the first three audience-facing Ground Zero Games
surfaces:

1. **BattleStarSol** — themed launch surface;
2. **X-Command** — standalone tactical-generator product demo; and
3. **d10SRD** — the rules commons and reference.

GZG:NOW and the remaining independent Pages stay public for development and
backend testing, but they are not the initial audience pitch.

## Run

The Page has no dependencies, account system, telemetry, or game server.

```text
npm test
npm run check
```

Serve `site/` with any static web server.
