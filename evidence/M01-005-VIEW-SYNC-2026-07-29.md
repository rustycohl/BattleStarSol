# M01-005 Camera-Synchronized Observation Evidence

## Finding

The M01 observation surface originally republished after UI and tutorial
changes. A live isolated Web run exposed a timing gap: camera focus uses a
0.35-second tween, so coordinates serialized at the start of the tween no
longer aimed at the rendered actor or target when the camera settled.

The gameplay cells, AP costs, and target identities were correct. Only their
projected screen positions were stale.

## Correction

The guided Web build now:

- samples a camera-position, camera-rotation, and viewport-size signature at a
  maximum of 10 Hz;
- does nothing while that signature is unchanged;
- rebuilds and republishes the bounded observation while the view is moving;
- stops rebuilding once the view settles;
- preserves immediate publication for ordinary UI and tutorial state changes.

The observation remains read-only. It does not read JavaScript, accept input,
or create a second gameplay authority.
